# macOS DMG Implementation Plan

> **For agentic workers:** Execute the three bounded packaging tasks in parallel, then integrate and verify the installed artifact in this chat.

**Goal:** Deliver an Apple Silicon DMG containing the existing app and every runtime dependency.

**Architecture:** Tauri 2 loads the existing Python HTTP UI from a supervised PyInstaller onedir sidecar. Application Support contains mutable state; Chromium and media binaries remain inside the read-only app bundle.

**Tech Stack:** Tauri 2, Rust, PyInstaller, Python 3.12, Playwright Chromium, FFmpeg/FFprobe, macOS Command Line Tools.

**Spec:** User's macOS DMG requirements in this chat, 2026-10-18.

## Global Constraints

- Migrate existing code; avoid unrelated refactoring.
- End users install no Python, Node, browser automation runtime, or media tools.
- Reuse existing Application Support data without overwriting it or embedding user data in the installer.
- Closing the app must reap backend and browser/task descendants.
- Target arm64, macOS 13.5+ (bundled Node minimum); build with Command Line Tools, without full Xcode.
- Verify native architecture, executable bits, linked libraries, and signatures.
- Test an app copied from the mounted DMG under a restricted environment and disposable data root.
- Report signing/notarization and external-account test limitations accurately.

### Task 1: Frozen backend runtime

**Files:** `desktop/backend_entry.py`, necessary compatibility changes in `ui_server.py`, `platform_compat.py`, `bootstrap.py`, `cleanup.py`; `tests/test_desktop_runtime.py`.

**Interface:** `--desktop-server --port 0 --parent-pid PID --ready-file PATH` produces JSON readiness including actual port and PID. Script, `-m`, and `-c` dispatch preserve existing subprocess invocation patterns.

- [ ] Audit subprocess calls and paths, then implement frozen dispatch and supervision.
- [ ] Make bundled dependency status independent of a system Python or virtual environment.
- [ ] Exercise source tests and the frozen executable's dependency/browser/media self-test.

### Task 2: Dependency packaging

**Files:** `desktop/requirements-build.txt`, `desktop/guizang-backend.spec`, `desktop/package_backend.py`, `desktop/audit_native.py`.

**Interface:** `dist/desktop/backend/`, `dist/desktop/browsers/`, `dist/desktop/media/` become Tauri resources. Include source scripts and static assets, exclude personal data.

- [ ] Pin the build dependencies in an isolated build virtual environment.
- [ ] Bundle the matching Chromium revision and self-contained arm64 FFmpeg/FFprobe.
- [ ] Produce a dependency manifest with versions, origins, hashes and licenses.
- [ ] Check native executable bits, architectures, links and signatures.

### Task 3: Tauri application

**Files:** `desktop/src-tauri/`, `desktop/frontend/`.

**Interface:** launch `Resources/backend/guizang-backend`, wait for readiness, then load the loopback URL; set bundled browser/media paths and writable user paths.

- [ ] Implement startup error reporting, single instance locking and owned-process cleanup.
- [ ] Preserve native directory selection, downloads, external links and durable UI preferences.
- [ ] Build the app using the existing application version.

### Task 4: Integration and installed acceptance

**Files:** `desktop/build_macos.sh`, `desktop/test_installed.py`, `desktop/README.md`, `desktop/TEST_RESULTS.md`.

- [ ] Build app, verify signatures, and generate compressed DMG with Applications link.
- [ ] Mount DMG, copy app into a clean installation directory, and launch using only system PATH and a fresh data root.
- [ ] Exercise HTTP UI, real browser/PDF automation, media conversion, import/export and restart persistence.
- [ ] Verify normal close and forced host termination leave no owned descendants.
- [ ] Record evidence, artifact hash, remaining external-service coverage and distribution caveats.
